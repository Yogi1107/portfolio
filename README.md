# 🚀 Yogiraj Bhilare -- Developer Portfolio

A modern and responsive personal portfolio website built with **React**
to showcase my projects, skills, coding profiles, and experience. This
portfolio highlights my journey as a **Full Stack / Data Science / AI
enthusiast** and provides an easy way to explore my work.

-   ✨ Clean and modern UI\

-   🧩 Projects showcase with modal details\

## ⚙ Installation & Setup

Clone the repository:

``` bash
git clone https://github.com/yourusername/yogirajbhilare-portfolio.git
```

Go to the project directory:

``` bash
cd yogirajbhilare-portfolio
```

Install dependencies:

``` bash
npm install
```

Run the project:

``` bash
npm start
```

Open in browser:

http://localhost:3000
